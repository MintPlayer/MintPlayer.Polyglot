# P40 — Library-grade output (issue #73) — implementation plan (dependency-ordered slices)

> Design contract: `PRD.md`. Investigation evidence: `ANALYSIS.md`. Issue: #73.
> **Status (2026-10-17):** designed, slice 0 done, **D1–D17 accepted** on #73 (D18–D20 derived), follow-ups
> folded in. **Implementation in progress.**

**Build discipline.** Implement ALL slices first, then build and run the full gate **ONCE** at the end
(`pwsh scripts/build-and-test.ps1` or `/build-and-test`). The mid-flight ceiling is `-Tier fast` or a bare
unit-test exe run. Commit per slice. Slice 0 (spikes) is the one exception.

**The POSIX leg is required.** A5, B5 and B7 change path handling and add CLI translation units, so one WSL
`cmake` + g++ compile and unit run is part of the end gate.

**One PR.** Every slice below — Core, all four manifests, CLI, MSBuild, gates, docs — lands together. Items
the investigation uncovered are in scope: generic member typing, class bounds, extension defaults, the PHP
`$` miscompile, `super`, the watch source-map bug, PHP `\Throwable`, and MSBuild `pgconfig.json` inputs.

**New gate legs go in bounded and flushing from the start** (the P39 CI-hang lesson): `Invoke-Cli`-style
timeouts, and no silent stdout buffering.
